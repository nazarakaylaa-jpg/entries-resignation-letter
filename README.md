Entry for the [make.fun](https://make.fun) competition
**The Funniest One-Line Resignation Letter** (`u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947`).

`main.ts` (Node 22, TypeScript, no network) writes one resignation letter —
in the voice of a cron job that has fired every minute since March — to
`/output/entry.txt`. The letter is 139 characters, one line:

> I fired every minute since March and the job was never the problem, you were, so I resign, effective next minute, when I fire again anyway.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
